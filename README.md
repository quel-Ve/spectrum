# 8cava — CAVA 风格 Windows 实时频谱

黑底、极简、渐变填充折线的实时音频频谱可视化。用 `sounddevice` 采集系统播放声音（优先「立体声混音」），PyQt6 自绘渲染，目标高刷新率平滑显示。原生 FFT 折线图（非 CAVA 柱状聚合）。

CAVA（<https://github.com/karlstav/cava>）上游源码作为算法/配置参考保留（`cava-master.zip` → `src/`），实际 Windows 工具是根目录的 `spectrum.py`。

## 运行

```powershell
# 使用虚拟环境或系统 Python（需已安装 numpy / sounddevice / PyQt6，见 requirements.txt）
python spectrum.py

# 列出输入设备
python spectrum.py --list

# 指定设备
python spectrum.py --device 9

# 调整刷新率/动态平滑（attack=上升权重，release=下降权重）
python spectrum.py --fps 120 --attack 0.8 --release 0.25

# 读取 CAVA 风格配置文件
python spectrum.py --config .\cava.config
```

## 交互

| 操作 | 效果 |
|------|------|
| 滚轮 | 垂直滚动 dB 定义域（-140…0 dBFS） |
| Ctrl+滚轮 | y 轴缩放（10dB 单元格高度；默认=最大单元格，滚轮下缩小至全 0..140，滚轮上放大） |
| 左键拖动 | 移动窗口（无边框） |
| 鼠标悬停顶部 | 弹出自动隐藏工具条 |
| R | 录制 / 停止 max-hold 包络 |
| C | 清空所有包络 |
| L | 对数 / 线性频率轴切换 |
| N | 音高（乐理）标注开关 |
| O | 循环内容透明度（100/70/50/25%，默认 25%；折线/坐标数字/dock 恒不透明） |
| Esc | 退出 |

## 技术说明

- **180 FPS**：默认刷新率 180，用 `PreciseTimer` 规避 Windows 默认 ~15.6ms 定时器分辨率（否则会被压到 ~64 FPS）。
- **更新率 ~188 Hz**：短窗 FFT_SIZE=4096 + 256 样本重叠滑动窗口（93.75% 重叠），频谱数据 ~188 Hz 更新。配合 180 FPS 插值，画面连续不卡顿。
- **双路径分层架构（2026-08-18，GPT 对齐）**：实时主线与录制/精细分析**分离**，互不污染——
  - **实时线**：短窗 FFT_SIZE=4096 全频段（窗 85ms/组延迟 43ms），**50Hz kick 也立即动**；
  - **精细参考线**：长窗 65536（20–500Hz，bin 0.73Hz）以暗色细线叠加在主线下方，显示低频真实频率结构（慢动态，不参与跟手）；
  - **录制包络**（max-hold）：走长窗精细网格（20–500Hz 约 8.5px/bin），EQ 预设对比有真低频细节。
- **非对称 Attack/Release 平滑**（替代单 EMA）：`attack=0.80` 上升快冲（kick 立即上冲）、`release=0.25` 下降慢落（保留独立鼓点形状，不融成平台）。
- **时频取舍**：低频精细与实时跟手受时频不确定性约束——实时线放弃低频真分辨（显示级平滑），精细结构交给独立参考线/录制层（详见 `docs/2026-08-18-spectrum-latency-analysis.md`）。
- **透明边缘（耳机频响基准）**：透明模式下，屏幕底部以 HD490 Pro 实测频响曲线为界——曲线以下为深色底带、以上透明露出桌面。频响曲线 1kHz 归零点固定于 **-70 dBFS**，y 轴按 **'+70dBFS'** 单位显示（显示值 = dBFS+70，基准线即 0）。
- **dB 定义域**：默认 110 dB 视口（`-110…0 dBFS`，显示为 `-40…+70`），纵向滚动于 `-140…0 dBFS`；**Ctrl+滚轮 y 轴缩放**改变 10 dB 单元格高度，span 110（默认=单元格最大）~140（全范围 0..140），滚轮下缩小、滚轮上放大。窗口高度 100px 对应默认 110 dB 视口（每 10 dB ≈ 9.1px）。频率域固定 20 Hz–20 kHz，不再横向缩放。
- **紧凑模式（窗口高度 ≤200px，2026-08-18）**：取消背景色与网格线，仅保留频谱内容浮动于桌面；网格仅在 >200px 时绘制（trans 开从 -70dBFS 基准线往下、关则全画）。Label 按钮切到 **Note** 模式时 x 轴频率数字替换为**每个半音的音名**（去八度、正常水平书写）；**Min** 模式隐藏 x/y 轴全部刻度数字，只留频谱与网格。默认高度 100px 即默认紧凑。

## 主题

单一 `sunset` 主题（橙粉，以 `#BD5075` 为中心），方角、无圆角，契合 Windows 10 风格。

`--config` 支持 `[theme]` 逐色覆盖，兼容 CAVA `[color]` 段（见 `cava.config.example`）。

## 原生窗口透明度（替代 win2blur）

**⚠️ win2blur 不能用于本窗口**：spectrum 是 Qt 分层逐像素透明窗口（`WA_TranslucentBackground`），win2blur 改变窗口样式/重建分层表面时与 Qt 渲染管线死锁 → 程序冻结必须强杀。不要对 spectrum 应用 win2blur 效果。

替代方案 = **内容透明度**（`[window] opacity`，默认 `0.25`，热键 `O` 循环 100/70/50/25%）：`QPainter.setOpacity` 逐像素作用于频谱内容，**dock 工具条恒不透明**（2026-08-18 起）。**折线与坐标刻度数字豁免原生透明度、恒不透明**；折线下方的渐变填充区及其余内容按原生透明度（2026-08-18）。

**点击穿透（2026-08-18）**：除 dock（底部工具条）区外，整个窗口 **click-through**——鼠标点击/滚轮直接穿透到下层窗口，不阻挡桌面操作。30ms 定时器轮询光标：光标进入 dock 区 → 移除 `WS_EX_TRANSPARENT`（可交互 + 弹出工具条）；离开 → 恢复穿透。dB 滚动/缩放/按钮操作需在 dock 区进行。

## 工具条 / dock（不透明，光标进入底部区弹出）

**Rec** 录制/停止包络 · **Clear** 清空包络 · **Dev** 循环输入设备 · **⏸** 冻结显示 · **dB** 重置视图 · **Log/Lin** 频率轴缩放切换 · **Label** 轴标注三模式循环（按钮显示当前模式）：**Freq** 频率/dB 数字 → **Note** 音名标注 → **Min** 隐藏全部刻度数字 · **Top** 置顶开关（**默认置顶**；关 = z-order 置底 HWND_BOTTOM 真正最底，纯背景条） · **Br** 左/下/右边框开关（**默认无边框**：内容占满窗口边缘，下方留 1px 给任务栏；开 = 恢复 5px 边框） · **⟳** 重载配置 · **高度滑块**（100–400px，默认 100；≤200px 进入紧凑模式）。右上角常驻 **✕** 关闭按钮，其左侧为曲线更新率（Hz）。

光标移到底部中心（±500px × 底部 60px）弹出；**dock 背景与按钮恒不透明**，也是唯一可交互区域（其余部分点击穿透到下层窗口）。

## (Trans, Top) 模式联动（2026-08-20）

窗口底边锚定策略由 **Trans** 与 **Top** 两键组合决定：

| Trans | Top | 行为 |
|-------|-----|------|
| 开 | 开 | **盖任务栏**：底边贴全屏底，置顶浮在任务栏/开始面板之上（透明显示，透过频谱仍可点按任务栏；周期性重申置顶防任务栏弹出压过） |
| 关 | 开 | **贴任务栏**：窗口底边紧贴任务栏上沿（落点下移 2px 贴平任务栏）；检测到任务栏**上沿滑动运动**（唤醒上移/收起下移）→ 滑动第一帧即触发 easeOutCubic 滑动动画（60Hz，位移=任务栏高度）：**唤醒 0.30s 无延迟 / 收起延迟 0.1s 后 0.40s**（匹配任务栏各自动画时长）；收起落点保留 1px 给隐藏任务栏边线 |
| 开/关 | 关 | **强制预览**：高度强制 300px、tint 强制 80（**与 trans 状态无关**，2026-08-20 优化）；底边贴回任务栏上方；**z-order 置底 HWND_BOTTOM**（真正最底，纯背景条）。再开 Top → 恢复默认高度 100 / tint 8 |

> **Top 切换（无论开/关）→ trans 自动关闭**（2026-08-20 优化：切 Top 即转实底；启动不触发，默认仍为 trans 开 + top 开 = 盖任务栏）。手动 **Trans** 按钮可随时重新开启透明。

实现要点：`FindWindowW("Shell_TrayWnd")` 查任务栏实时 rect——窗口内（常显或自动隐藏弹出）取其顶边为锚点，屏外（自动隐藏收起）则以全屏底为锚点。**贴任务栏动画（2026-08-22）**：任务栏唤醒/收起是固定速度/时间/位移的**滑动**（~0.2s）。旧检测卡在"底边未完全出屏"（`bottom<=屏底+1`）才翻状态 → 唤醒要等滑动到末段才触发、频谱落后 ~0.2s（且旧跟随因同一条件只有"原位/到位"两态）。改为 **60Hz 检测任务栏上沿 y 的位移**：上移=唤醒、下移=收起，滑动第一帧即触发 easeOutCubic 滑动动画到**最终锚点**（位移=任务栏高度，不追中间态），**唤醒无延迟（`ADHERE_WAKE_DELAY_S=0`）+0.30s / 收起延迟 0.1s（`ADHERE_COLLAPSE_DELAY_S`）+0.40s**（`ADHERE_ANIM_S` / `ADHERE_ANIM_S_COLLAPSE`，2026-08-22 实测任务栏唤醒与隐藏动画时长/起步不同）；唤醒落点下移 `ADHERE_END_OFFSET=2`px 贴平任务栏，收起落点保留 1px（隐藏任务栏仍露出 1px 边线）——系统动画关（rect 跳变）同样瞬时响应。贴任务栏模式下若窗口被拖离底部超过 250px 则停止跟随（不打扰手动摆放）。所有锚点均留 1px 底线（`BOTTOM_GAP`），保证频谱底线不贴死。**top 关 z-order 置底（2026-08-22）**：非置顶时 `SetWindowPos(HWND_BOTTOM)` 把窗口压到所有窗口之下成为纯背景条（不再是停在原 z 序高位浮在其他窗口之上）。**置顶盖任务栏受 Windows 层级限制**：任务栏本身即 topmost，频谱通过周期性重申置顶（0.15s，2026-08-22 由 0.5s 加快）维持在其上——任务栏缩略图预览把 spectrum 临时顶起后 ~0.15s 内夺回；开始面板位于系统更高层级，普通 topmost 窗口无法压过（也不应压过，点开开始菜单是要操作它）——若你确认需要压过开始面板，这属于系统级限制，需另行方案。

## 轴标注模式（Label 按钮，学音乐辅助）

按 **Label**（或 `N`）在三种轴标注模式间循环：**Freq**（默认，x 轴频率数字 + y 轴 dB 数字）→ **Note**（音名标注，本节内容）→ **Min**（最简，隐藏全部刻度数字，只留频谱与网格）。

Note 模式标注乐理音高（`C4`、`C#4`…，A4=440Hz），每条刻度对应一个半音。标注覆盖**整个显示频段**：从 E0（20Hz）铺到 D#10（≈19.9kHz），超出标准 MIDI 顶（G9/12.5k）的高音名由公式扩展（`D#10` 这类实际没人用的音），纯为把 20 Hz–20 kHz 的频谱图铺满。看到频谱峰就能直接读出对应音名，辅助练耳/学乐理。

音高名称**跟随耳机频响曲线**排列：每个音名中心位于频响曲线（1kHz 归零 @ -70 dBFS）下方 15px，随曲线起伏——3kHz 峰处文字上抬、9~14kHz 测量深谷处文字下沉。

音高音量数字以 **'+70dBFS'** 显示（dBFS+70），下限 **-40**（= -110dBFS）钳制不再波动；颜色随符号变化：负 → 偏红、正 → 偏绿（2026-08-18）。

**紧凑模式（窗口高度 ≤200px）+ Note 模式**：跟随曲线的音名隐藏，x 轴频率数字改为**音名去八度**（`G#6` → `G#`）、正常水平书写，颜色沿用原刻度数字。

## 包络录制（验证 EQ 预设是否生效）

按 **Rec**（或 `R`）开始录制，工具累计「每个频率达到的最大分贝值」；再按一次停止，冻结成一条包络曲线。重复可录多段（异色，右上角图例编号），**Clear**（或 `C`）清空。

典型用法：
1. 播放测试音频（预设 A），按 `R` 开始 → 播完按 `R` 停止 → 得到第 1 条包络（红）。
2. 切换 EQ 预设到 B，重播同一段音频，再录一段 → 第 2 条包络（黄）。
3. 对比两段曲线在目标频段的相对高低，即可确认预设是否真的改变了频率响应。
